# Student Management System

A simple **console-based Student Management System** built with **Python**.

This project allows users to manage student information such as name, age, and score through an interactive command-line menu.

## Features

* Add a new student
* Display all students
* Search for a student by name
* Delete a student
* Edit student information
* Sort students by name
* Search students by minimum score
* Display student statistics
* Delete all students
* Exit the program

## Student Statistics

The statistics section provides useful information including:

* Number of students
* Highest score
* Lowest score
* Average score
* Number of passing students
* Number of failing students
* Best student
* Worst student

## Requirements

* Python 3.x

No external libraries are required.

## How to Run

Clone the repository and run the `main.py` file:

```bash
python main.py
```

Or simply run `main.py` using your preferred Python IDE.
